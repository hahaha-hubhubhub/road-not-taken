# 《没走的路》亮色 iOS 风格预赛 Demo · 美术与交互说明 v0.3

> 2026-10-13。实现入口：[`web/demo.html`](../web/demo.html)；前端纯 HTML/CSS/JS，旧硬件体验仍在根路径 `/`。**本稿记录当前预赛原型，不代表真实模型和硬件均完成验收。** 它覆盖此前“深色平行档案室”的视觉方向，不改变后者关于安全、双路与反驳真实性的原则。

## 1. 视觉概念

**一句话**：一枚糖果色的双面胶囊，先装一条想象与一处留白；只有用户自愿补充，才让两条虚构情境互相回望。

- 从团队本地 `ui-reference/` 参考素材提取高饱和渐变、软质卡片、悬浮装饰和大圆角的**设计语言**，不在页面直接使用参考 JPG，不复制其产品画面和文案；第三方参考图不随仓库发布。
- 类 iOS 的触感：大字标题、胶囊状标签、半透明光感表面、圆角浮层、安全区、44px 以上点击区域；不是模仿 iOS 系统设置或医疗 App。
- 原创母题：分岔蓝路与橙路、同一扇窗的两种天气、粉白双面胶囊、可以带走的纸芯。插画由内联 SVG 与 CSS 绘制，当前**不是 AI 生图**。
- 情绪基调明亮但不轻视遗憾；“毒药”是叙事隐喻，不提供食用或医疗指导。不能把疾病、贫困、死亡、具体人物过错当笑点。

## 2. 设计 Tokens（当前 Demo 实际值）

| 用途 | Token / 值 | 说明 |
| --- | --- | --- |
| 底色 | `--cream #fff9f2` | 暖白，保留呼吸感 |
| 正文 | `--ink #202447` | 蓝黑色，浅底正文 |
| 次要文字 | `--muted #626984` | 不用过浅灰承载说明 |
| 主操作 | `--blue #3556d9` → `#4563d2` | 白色加粗按钮文字，重要区域高对比 |
| 未走之路 | `--orange #ff773f` | 大标题、道路、插画，不单独承载小字 |
| 惊喜色 | `--pink #ff5d9a` | 胶囊、星芒、引导焦点 |
| 边界与表面 | `--line #e6e3eb`、白卡 | 卡片通过表面与阴影分层 |
| 圆角 | 12 / 17 / 28 / 31 px | 标签、按钮、卡片三层尺度 |
| 字体 | 系统 UI + PingFang SC 回退 | 不依赖外网字体 |

渐变只出现在大面积装饰和操作面；**叙事正文始终在不透明浅色底上**。蓝／橙表达两种视角时，必须同时写出“现在／没走”的文字，不能只靠颜色传递意义。

## 3. 页面与组件

1. **输入**：亮色大标题和原创岔路插画；100 字输入、默认不选的六种关注角度（时间/经济/关系/成长/表达/节奏）与自定义短文本、可展开的现实线索选填、实时字数、预置案例入口和明确的数据传输告知。收起现状输入会清空；无模型时自定义生成不可冒充预置输出。
2. **生成**：静态文字说明真实等待时间，缓慢转动胶囊；不显示假进度或伪造“思考中”的步骤。可返回修改输入，迟到响应不再覆盖界面。
3. **双路**：蓝／橙并置卡片：若没有自愿提供现状，现实侧由服务端写入固定“未知”文案，AI 只生成另一条路；若提供一句现状，仅把它作为虚构推演的线索，不宣称认识用户。预置案例则是虚构角色。交换顺序、前提与技术来源可操作，桌面并排、手机堆叠。
4. **异议与改判**：真实模式先展示旧判断，再由第二次模型请求返回新判断、对变化的简短解释和纸芯短句；失败时保留初稿。离线案例只有**一条固定异议 + 固定预置文案**，不响应用户自由文本。
5. **纸芯**：轻 3D 胶囊入场，旁边展示文字纸芯；浏览器打印对话框可保存 PDF 或用普通打印机打印，**不是自动卷纸/封壳/出仓**。打印样式仅保留 80mm 纸芯。
6. **设置**：独立模态，对服务地址、模型、Key 明确告知存储与传输边界；键盘焦点限制在模态内，Escape 可关闭。

## 4. 动效与可访问性

| 动效 | 目的 | 减少动态效果 |
| --- | --- | --- |
| 屏间 420ms 淡入上移 | 确认进度切换 | 即时呈现 |
| 生成时胶囊缓慢摆动 | 告知还在等待，不代表 AI 内部推理 | 静态胶囊 + 实际秒数 |
| 纸芯阶段胶囊滚入 1s | 任务完成奖励，提示纸芯可带走 | 静态终态 |
| 主按钮按压 / 选中 | 操作反馈 | 不依赖动画，保留选中形状与颜色 |

普通文字目标 WCAG AA ≥4.5:1；按钮/输入/卡片结构与 focus-visible 明确；390×844、375×667、桌面 1366×768 为优先验收尺寸，320px 宽回退两列选择按钮；手机安全区和打印布局独立。不得自动播放声音。

## 5. AI 技术叙事与未完成事项

- `/api/parallel/create`：仅收到未走选择时，用较小的结构化 schema 只生成未走之路；现实侧保持固定留白。仅在用户自愿补充现状时，才用双路 schema 虚构两种情境；关注角度可不选或自定义。
- `/api/parallel/revise`：用户主动异议后第二次模型调用只修订结论、理由与纸芯短句。响应经过 schema 与内容规则校验。界面仅展示可读的变化解释，**不展示或伪称隐藏推理链**。
- 静态预置案例、真实模型、无 Key、MOCK_LLM 模式有不同标签与错误提示。当前真实模型质量与响应时长仍需用现场网络和真实 Key 验证；并非已完成硬件联调。
- 当前不支持持久化、分享权限、自动机械胶囊或模型实时插画。评委预赛请先用非敏感的示例输入；正式开放前仍需补齐隐私策略、滥用/额度限制与更多内容安全测试。

## 6. 验收清单

- [ ] 10 秒理解“两条路彼此回望”，知道内容是虚构。
- [ ] 无 Key 时自定义输入不产生伪 AI，预置案例固定异议可完整走到电子纸芯。
- [ ] 有 Key 时关注点影响首轮结构化调用，异议触发**第二次真实请求**；前后文本与耗时可辨。
- [ ] 超时与敏感输入有安全提示；不把失败后的静态案例偷换成实时生成。
- [ ] 375px 无水平溢出、键盘可走完全程、减少动态效果为静态；打印纸芯无网页装饰。
- [ ] 真机没出纸/未装胶囊时绝不声称“已交付实体胶囊”。

## 7. 隐私与文案修正（v0.3）

- 不再提“这次你最在意什么？”：它隐含 AI 能判断用户当下心理。新问题为“你希望故事更关注哪一面？（选填）”；默认不选、支持取消选中和自定义。
- 默认**不询问真实身份或完整经历**；现实线索折叠且选填，收起即清空。填写会随请求发送给配置的服务端与模型供应商；本地服务不持久化，但不能替供应商承诺不留存。
- 没有现实线索就不能让 AI 描写“现在的你”。模型调用只生成没走的路，服务端插入“现状未知”的固定卡片；预置案例称为虚构角色。
- 有现实线索也不能将模型情境说成用户事实；结果显示“基于你提供的线索想象”，并允许跳过质疑。正式公开部署仍需审查 CORS、密钥、速率限制及模型服务条款。
