## 1. 一句话视觉概念

**一颗会说话的后悔药。** 纸白底、一个高饱和主色、一张带全息箔光泽的热敏票；票正反面翻动时，用户正对着机器做同一个「翻面」动作——**屏幕里的翻转与手上的动作同构**。

参考站点给的是交互语言，不是画面：3D 翻面、跟随指针的全息箔、回弹入场。

| 区域 | 内容 | 规格 |

## 4.5 票面 = 三格漫画（硬约束）

票面是一条三格漫画，不是条目清单。三格标题固定：**01 · 看起来 / 02 · 后来 / 03 · 那边的我**。

- **第 1 格**是滤镜（那条路最诱人的样子），**第 3 格**是滤镜碎掉的那个「我」。少一格都不成立：只有 1、2 格是冒犯，补上第 3 格才是安慰。
- **格内插画用本地矢量线稿**，5 套模板按文案关键词匹配（窗 / 桌 / 队伍 / 机器 / 镜子）。**不是实时 AI 出图**——现场断网、出图延迟、风格漂移，三格漫画必须秒出且每次一致。美术同学请按「2.2px 黑描边 + 纯白底 + 圆角 15px」的单一笔触风格扩这套模板，别混风格。
- 打印时线稿转黑白（`grayscale(1) contrast(1.15)`），与热敏纸真实输出对齐。
- 正面第 2、3 格留白是**设计**，不是没做完：空白就是「你还没告诉机器你想知道什么」。
- 打印媒体里只出背面。

## 4.6 手机动作：六个动作的真传感器判定（`/` 联调台，2026-10-13 起）

动作**不靠点按钮**：手机真的翻过去、真的摇三下、真的按住屏幕两秒，页面才记一次数。做满规定次数，机器才开工。判定代码在 `web/app.js`（`GESTURES` / `DEV`）。

| 动作 | 提示文案（按钮副标） | 传感器 | 阈值 | 读数框显示 |
| --- | --- | --- | --- | --- |
| 翻个面 | 把手机翻过去再翻回来 | 陀螺仪 | 相对基准 ≥ 110° | `翻转 37° / 110°` |
| 摇一摇 | 用力摇三下 | 加速度计 | 连续 3 次 ≥ 2.1 g，间隔 ≥ 260ms | `2.4 g · 已捕捉 2 次` |
| 按住不放 | 按住读数框两秒 | 触摸事件 | 按住满 2000ms | `按住 1.3 秒 / 2.0 秒` |
| 拍一下 | 在手机背上拍一巴掌 | 加速度计 | 单次尖峰 ≥ 3.2 g，且前 0.5 秒安静 | `3.4 g · 已捕捉 1 次` |
| 吹一口气 | 对着话筒吹一下 | 麦克风 RMS | 连续 3 帧过阈值 | `气流 41 / 门槛 16` |
| 放平别动 | 放平，数三秒 | 陀螺仪 | 3 秒内漂移 ≤ 6° | `漂移 3° / 允许 6°` |

交互与文案规范：

- **选动作 → 面板展开**：点一个动作，下面展开一块面板（动作标题 + 读数框 + 进度条 + 「换一个动作」），同一时刻只武装一个动作。
- **进度可见**：读数框实时显示当前值与门槛（不是抽象「正在检测」）；进度条 0→100% 跟动作幅度走。
- **计数即反馈**：每记一次数，卡片闪一下 + 短震（`navigator.vibrate`），计数从 `1 / 3` 往上走，机器那排圆点同步点亮，让人看出「动作没到就不打」。
- **做满还要再来**：没做满时读数框写「重置好了，再来一次。」**已经做满、松手晚一点不算失误**（不出现「松早了」）。
- **8 秒兜底**：8 秒没读到就给一条提示（确认用手机、确认是 HTTPS），并保留手动确认按钮，别让人干等。
- **非安全上下文照实说**：`http://` 打开时，页面顶部明写「这页是 http 打开的非安全地址，浏览器直接禁用了陀螺仪、加速度计和麦克风——手机动作只能靠「按住不放」」，并把需要传感器的动作置灰、副标写「需要 HTTPS」。**不要假装还有别的办法。**
- **iOS 权限必须在用户点击里申请**（`DeviceOrientationEvent.requestPermission`），拒绝后不崩，退回「按住不放」和手动确认。

**诚实边界（不许改坏）**：

- 没接实体设备时，一个动作做满次数 → 走 `/sessions/:id/simulate-action`（服务端标记 `simulated`），页面写「点击按钮模拟打印与胶囊封装；不会得到实物」。
- **接了实体设备时，手机动作只算热身**，真正放行仍以机器回报的 `action_complete` 为准，做满手机次数也不代机器签字。

## 5. 动效清单

| 动效 | 规格 | 目的 |
| --- | --- | --- |
| 票入场 | 从上方落下 + 旋转回弹（约 700ms） | 像把票掷在桌上 |
| 全息光扫 | 跟随手指 / 陀螺仪，`mix-blend-mode` | 箔质感，鼓励上手摸 |
| 翻面 | `rotateY(180deg)`、`--flip`、`--spring`、`preserve-3d` | 与硬件「翻个面」同构 |
| 动作确认 | Vibration API 短震 + 卡片闪一下 + 圆点打勾 | 确认「我的动作生效了」 |
| 读数反馈 | 读数框实时刷新数值、进度条随手势增长 | 让人知道机器真的在读，不是装样子 |
| 打印吐纸 | 连续位移 + 轻微纸抖动 | 把等待变成期待 |
| 卷纸 | 连续滚动卷曲，不跳帧 | 完成仪式 |
| 胶囊落下 | 弹一下停住 | 交付感 |

- 同一屏最多 1–2 个运动元素。
- `prefers-reduced-motion: reduce` 时全部改为静态淡入，动作提示用文字与静态图标替代。

## 6. 文案规范

- 动作名 = 动作本身，不造词：**翻个面 / 摇一摇 / 按住不放 / 拍一下 / 吹一口气 / 放平别动**。每个名字说出口就知道手该怎么动。
- 不出现「故障牌」「账单暴走」「多米诺」等需要解释的词。
- 每个动作配一行大白话，说清「会发生什么」。
- 按钮只写用户要做的动作，不写系统术语。
- 语音是**这台机器的嘴**：毒舌、短句、冷幽默。先照着那条路的广告词念一遍，再把账本拍上去。
- **枪口朝路，不朝人**：损的是那条路、那门生意、那套流程、房东、物业、算法，不是坐在机器对面的人。
- 不许和稀泥、不许升华、不许说教：禁止「其实每条路都有好有坏」「重要的是你自己的选择」「你已经很棒了」。
- 三格文案的分工：第 1 格要美到让人心动，第 2 格要狠到具体到数字，第 3 格必须**那条路上的「那个我」自己认命**，不是我们替玩家下判决。
- 具体物件、具体数字优先：「改到第八版」「三桌同时预约落日」「第七页小字」比「各种压力」好笑一百倍。
- 不硬塞热梗和 emoji。
- **唯一不写成段子的地方**：危机路径。命中自杀 / 自伤表述时只给支持性文字，不出现玩笑，不出票。

## 7. 可访问性

- 主按钮 ≥ 88px 高、≥ 44px 点击区；底部安全区适配 `env(safe-area-inset-bottom)`。
- 键盘可完整通关，焦点可见，`aria-pressed` / `aria-live` 正确。
- 颜色不单独承载状态，必须配文字或图标。
- `320 / 375 / 390 / 430px` 宽度不横向溢出。
- 音效默认关闭，仅用户触发。

## 8. 隐私与诚实边界（保留）

- 默认**不询问**真实身份、姓名、联系方式或完整经历；现实线索折叠且选填，收起即清空。
- 没有现实线索时，AI 只写没走的那条路，现实一侧由服务端写固定「未知」，不替用户编造。
- 输入内容会发送给配置的服务端与模型供应商；本地服务不持久化，但不替供应商承诺不留存。
- **硬件状态必须诚实**：没连设备就说没连；模拟就说模拟；打印、卷纸、出仓以传感器回报为准。
- 展示胶囊**不可吞食**，不做药品式警示包装。
