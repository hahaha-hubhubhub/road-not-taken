# 《没走的路》预赛界面美术需求文档 v0.1（历史深色提案）

> 当前明亮 iOS 风格已改用 [v0.3 美术与交互说明](DEMO_UI_ART_BRIEF.md)。本文件保留原始构思和安全/AI 原则，不再是本次 Demo 的色彩规范。

> 2026-10-13｜历史阶段的设计讨论，**本文不是当前已实现 UI 的规范，也不代表已完成真机联调**。适用场景：评委坐在笔记本/平板旁，近距离操作 1–2 分钟；手机可作私人输入端，不依赖远距离大屏或自动胶囊机构。承接 [双面胶囊差异化方案](DIFFERENTIATION.md)。

## 1. 美术任务与体验目标

**一句话创意**：把“平行人生”设计成两份可以交换座位的档案；AI 先写出两个自己，再接受用户的一次质疑，最终把重新理解的一句话封进**展示道具**的胶囊。

- **主要目标**：评委前 10 秒知道这是“两个自己互相回望”，不是占卜/心理诊断；1 分钟内亲手完成一次**选择→AI 响应→提出异议→AI 修订**，肉眼可见内容真的变化。
- **视觉性格**：文学性、神秘但不阴森；“档案室 × 热敏纸 × 微弱的平行光”。偏互动叙事/编辑设计，不做医院、药房、赛博 HUD、三维粒子堆砌。
- **部署形态**：P0 一台 13–16 英寸笔记本（建议按 1366×768 和 1440×900 出稿）+ 390×844 手机；优先用借来的实体旋钮完成“选择关注点”，配一个 LED 做状态反馈——这是预赛最小的真实硬件参与，不需大场地。若联调不及，应退到网页同操作并明确标注“硬件交互原型未完成”。**大屏投影、多人围观、全自动出胶囊均非预赛 P0**。
- **内容原则**：AI 对另一条路只作“可能的虚构情境”，两条路都有所得和代价；风格可以荒诞，不把重病、死亡、贫困或真实人物过错作为反转。用户可以不接受 AI 的判断并退出。
- **成功检查**：让 5 位首次看到原型的人在无人解说时说出“两个自己”的关系，并指出自己刚才的质疑改变了哪里。此为设计验证目标，非已测结果。

### 设计参考的采用边界

使用 `ui-ux-pro-max` 的 **Editorial Grid / Magazine** 作为信息层级参考、进度/减少动态效果作为交互检查；其自动生成的通用落地页模板和英文字体组合不适合中文互动叙事，**不原样照搬**。保留现有项目的小票材质语言，但让双路对照成为视觉主角。

## 2. 预赛体验与 AI 可见性

| 步骤 | AI 真正做什么（拟实现） | 界面必须让人看到什么 | 不允许伪装 |
| --- | --- | --- | --- |
| 01 岔路 | 用户输入“如果当时…”，用实体旋钮或等价网页控件选择最在意的维度；第一轮模型在**一次结构化调用**里提炼岔路、未确定的假设、两条路的所得/代价、彼此回望及几个候选结语 | 输入像在填写一张私人档案；维度卡片/旋钮会影响后续文本；结果里可查看“本次只是依据哪些假设想象” | 不展示“AI 精准识别了你真正的心理需求” |
| 02 对照 | 展示第一轮模型的**真实**双路输出 | 同一人物视觉语言的两张档案，逐段对应：吸引力／日常代价／反向羡慕；可切换先听谁说 | 不把排版动画称为实时推理或流式生成 |
| 03 质疑 | 用户选择一个具体异议，例如“我并不在乎收入，我在乎决定自己时间”；第二轮模型**只修订这个判断与收尾**，保留不相关事实 | 左右并列“原判断→你提出的异议→新判断”，用细线标注改动点；失败时保留原文并可重试 | 如果没有真实第二次调用，不能把本地换卡称“AI 自我修正” |
| 04 收束 | 把用户确认的一句短句/两条路对照排版成手机可保存的“胶囊内芯”；若真机在线可打印 | 胶囊是叙事收尾；清楚区分电子版、真实打印、模拟封装 | 无设备不得显示“实体胶囊已出仓” |

**技术展示开关（评委演示专用）**：提供一个不会覆盖故事的“本次 AI 如何参与？”抽屉：本次用到的输入维度、结构化字段、第一轮生成耗时、第二轮是否真的调用与耗时、内容安全状态（仅展示规则结果）。不展示模型隐藏推理链、原始 API Key、完整私密输入或伪造的思考过程。真实模型与离线案例有持续可见的不同标识。

**调用与延迟**：第一轮等完整结构化结果后再揭晓；第二轮仅在用户主动质疑时调用，超时可保留初稿并明确提示。P0 不把 AI 出图放在等待链路上；可选 P1 异步生成**一张双世界共用构图**，不成功就用已审核的预置视觉并标“预置插画”。新双路 Prompt、第二轮修订、图片模型都**尚未接入**，需技术团队验证能力和耗时。

## 3. 视觉方向：平行档案室（推荐一案）

### 3.1 视觉叙事

- **空间层**：深蓝炭黑是两条路之外的“未确定空间”；两张暖纸色档案从同一条分岔线生出，像被灯照亮的未寄出明信片。
- **两条路**：现实线用暖琥珀细线/页码标记，另一条线用低饱和紫色；两者**同尺寸、同字重、同信息密度**，不通过色彩暗示哪条更正确。
- **共同点**：两路交叠处用一段短弧/透明重叠形成“被你带走的一点”；胶囊只在最后变成容器，不从首页就出现医疗包装。
- **质感**：纸纤维、轻微压印、档案编号与热敏文字可以点到为止；纹理不盖正文，阴影不过度拟物。避免伤害性视觉：破碎人体、血迹、骷髅、警告药盒、处方用语。

### 3.2 设计 Token（建议值，出稿时复核对比度）

| Token | 值 | 用途 |
| --- | --- | --- |
| `--night` | `#15191D` | 主背景 |
| `--night-surface` | `#20262A` | AI 说明抽屉、深色次级区 |
| `--paper` | `#F5F0E7` | 双路档案、胶囊结果 |
| `--paper-ink` | `#1D262B` | 纸面正文 |
| `--night-ink` | `#F5F0E7` | 深底主文字 |
| `--night-muted` | `#B8C3C5` | 深底次要说明 |
| `--paper-muted` | `#4B555A` | 纸面次要说明 |
| `--present` | `#F2B56B` | 现实线标记（深底） |
| `--alternate` | `#B8AAFF` | 另一条路标记（深底） |
| `--action` | `#B84B37` | 主按钮底色，配白字 |
| `--focus` | `#6B48BB` | 焦点环/纸面强调，配白字时复核 |

对上述指定配对做过**初步** WCAG 对比计算：纸面正文/纸底约 13.6:1，主按钮白字/红底约 5.1:1；成稿仍需逐控件校验普通文本 ≥4.5:1、非文字控件边界 ≥3:1。不要直接沿用现有 `#c8472f` 作深色背景上的小字（该组合约 3.85:1）。颜色之外，始终有“现在/未走”文字和图形区分。

### 3.3 字体、网格、组件

- 中文 UI：系统无衬线（`PingFang SC / Noto Sans SC / Microsoft YaHei` 回退）；两路故事：系统宋体/思源宋体可用时启用；编号与结构化标签：等宽字体。**不得依赖外网字体才能正常阅读中文**。
- 笔记本 1366×768：内容最大宽度建议 1120px，左右档案等宽，间距 20–28px；上方仅保留标题/进度/模式，底部一条明确主操作。AI 抽屉按需打开，不占两路正文区域。
- 手机 390×844：同一组内容变成“现在的我 / 没走的我”两张可切换卡，切换状态保留、不可横向挤成双窄栏；底部固定主操作不遮挡系统安全区。兼容 375×667 与 320px 宽、200% 字体放大。
- 字级建议：大标题 32–40px（手机 28–32）、档案标题 22–26、正文 ≥16px/行高 1.55–1.7、辅助信息 ≥13px；故事一段宜 2–4 行，不在卡内长篇滚动。
- 按钮/旋钮替代控件至少 44×44px；键盘焦点明显、Tab 顺序正确；卡片选择有选中/禁用/加载/错误四态；滑动可选，但所有核心动作都能点击/键盘完成。

## 4. 分屏与逐屏美术要求

| 页面/状态 | 主视觉与层级 | 需要设计的元素 | 特别要避免 |
| --- | --- | --- | --- |
| S0 入口 | 中央一条岔路向两张未展开的纸延伸；标题“没走的路”，一句解释 + 明显“开始” | 标识、岔路矢量图、演示案例入口、隐私与虚构提示 | 首页同时出现长报告、医学图标、十个玩法入口 |
| S1 输入/选维度 | 两张空档案封面，现实线/未走线只标方向；文本框和四张价值卡成为焦点 | 表单标签/计数/示例 chip、选中反馈、语音不可用状态 | 用占位文字代替标签；把敏感原文放大屏 |
| S2 AI 正在生成 | 两份档案仅露出封面与真实耗时；安静的分岔线呼吸 | 有文字的状态、取消/返回、离线与模型错误 UI、离线案例标识 | 伪造“37%/思考第 3 步”或假流式字幕 |
| S3 双路故事 | 两张同等权重档案；“吸引/代价/回望”并排对齐，关键反转句有一次聚焦 | 档案头、人物/场景共用视觉母题、互换视角控件、假设说明入口 | 左边代表正确、右边代表错误；一屏塞满长故事 |
| S4 质疑与修订 | 一张覆盖在两路之上的“改判纸条”，从旧句到新句用可读的差异高亮 | 质疑卡、自由输入（可选）、修订中/成功/失败、接受初稿/跳过 | 每次改判整个故事突然替换，用户不知道变了什么 |
| S5 胶囊结果 | 上层屏幕是两路摘要，下层出现纸带卷成展示胶囊的静态终局；保存/退出清晰 | 小票预览、展示道具警示、打印状态/模拟标签、无设备回退 | 明明没真机却写“已出药”；让分享按钮比退出更醒目 |
| SX 危机与敏感内容 | 退出双路游戏，转为清楚、平静的安抚界面 | 简短安抚、联系可信的人/当地援助文字、关闭按钮 | 黑色幽默、彩蛋、胶囊动画继续播放 |

**笔记本结构草图（信息架构，不是视觉稿）：**

```text
┌ 标识/本次为虚构故事 ── 进度 2/4 ── 真实模型·演示案例标识 ┐
│                 一句话问题 / 本次选择的维度               │
│ ┌────────── 现在的我 ──────────┐ ┌────── 没走的我 ──────┐ │
│ │ 所得 → 代价 → 回望            │ │ 所得 → 代价 → 回望    │ │
│ │ 同一个视觉母题                │ │ 同一个视觉母题       │ │
│ └──────────────────────────────┘ └───────────────────────┘ │
│      交换视角       看假设       我有异议 / 继续            │
└───────────────────────────────────────────────────────────┘
```

## 5. 动效与声音（服务叙事，不假装模型能力）

1. **唯一重头动效**：从 S3 “两个自己换位”到反向羡慕句出现，左右档案平移/交叉淡出，最后停在可读状态；输入时可直接跳过，不锁操作。其余动效仅用于操作反馈。
2. **质疑前后**：先让旧句保留在上层，再使新句出现并标出替换片段；不要整屏抖动、打字机逐字拖时长或闪白。
3. **胶囊收束**：屏幕纸带卷起为比喻；只有真机回报出仓后才出现“已交付”，无硬件只显示“电子胶囊/模拟效果”。声音可选且默认关闭或由用户触发，不自动大声播放私密内容。
4. 一屏最多 1–2 个主要运动元素；`prefers-reduced-motion` 时用即时淡入/静态结果替代翻转和卷纸；键盘与读屏能先读取最终内容。给视觉焦点一个可见状态而不是只有颜色变化。

| 资产 ID | 交付物 | P级 | 建议格式/规格 | 应用与约束 |
| --- | --- | --- | --- | --- |

| A02 | “分岔→重合”路径母题（桌面/手机） | P0 | SVG/可编程路径 | 两路地位相等，可键盘/减少动态效果静态展示 |

| A08 | 三段动效分镜：双路出现/换位/胶囊终局 | P0 | 每段 4–8 张关键帧或简短原型 + 时序表 | 设计正常/减少动态效果两套；不交无法复刻的仅视频效果 |
| A09 | 小票/胶囊内芯排版规范 | P1 | 384px 黑白稿 + 实际热敏机打样照片 | 数字结果与物理打印要同内容；机型未定前只作候选 |
| A10 | 可选 AI 共用构图插画与生成规范 | P1 | 两路一致人物/母题提示模板、人工审核样例、失败占位图 | 不阻断主要流程；明确图库版权及用户输入的模型处理告知 |

**命名与交付**：`ui/` 下按 `screens/`、`components/`、`assets/svg/`、`assets/raster/` 分类；源文件保留字体回退、颜色变量、组件不同状态、动效关键帧和导出清单。这里是美术交付要求，**本轮不创建真实 Figma 文件或图片**。图像生成素材如未来采用，应记录模型来源、使用范围、是否可印黑白，以及失败时的版权安全备选。

## 7. 设计验收与内容边界

- [ ] 第一次看 10 秒能说出“双路对照”，且知道是虚构，不误认为 AI 在预测或提供心理治疗。
- [ ] S1 的选择改变真实生成条件；S4 的质疑触发**真实第二轮**修订或诚实标明离线降级；新旧差异可辨认。
- [ ] 双路线在文字长度差异 2 倍、单路缺少某字段、手机 320px/桌面 1366px 下仍对齐或有明确缺省占位；不截断重要叙事。
- [ ] 各控件有 hover/focus/pressed/disabled/错误反馈，触控目标 ≥44px，键盘可完成全部关键流程；纯文字状态不只靠颜色。
- [ ] 指定文本配对符合 WCAG AA 普通文本对比 ≥4.5:1，200% 缩放不丢内容；支持减少动态效果，不用强制自动播放声音。
- [ ] 加载、Key 未配置、生成超时/失败、离线案例、危机输入、打印失败、无硬件均有独立视觉状态；不可用状态不说“已生成/已出仓”。
- [ ] 真实个人输入不在演示笔记本公开投屏；公开素材均为非敏感审校样例；分享是显式选择而非默认打开。
- [ ] 输出故事与模型名、耗时、降级状态的展示来自实际接口；不展示模型隐藏推理链或杜撰 AI 的“自检结果”。

## 8. 待团队确认（不阻止先出低保真视觉稿）

1. 预赛评委是**操作同一台笔记本**，还是体验者在手机输入、评委看笔记本？默认先画“笔记本主体验 + 手机自选隐私模式”。
2. 预赛规则是否硬性要求真机出纸？若否，纸带/胶囊可作电子结果与**明确标注**的原型视频；若是，A09 上升 P0，先锁打印机。
3. 第二轮 AI 修订可接受的最长等待是多少？需要在已知真实模型耗时后决定提示和超时回退；当前无法凭文档保证 100 秒内完成。
4. 两路内容是否允许 AI 分析用户真实选择？若只给“如果当时…”，现实线缺事实；UI 必须向用户补问“现实中你当时选了什么”或把现实线标作**假设**，不能伪造用户经历。
5. 隐私与分享默认值、是否准许 AI 出图处理私人输入，需由团队在真实用户测试前确认。
