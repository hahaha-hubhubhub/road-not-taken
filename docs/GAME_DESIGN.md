# 《没走的路》现场体验策划案 v0.5

> 2026-10-13，本地评审稿，**未提交或推送**。可玩入口 `/demo.html`；根路径 `/` 是设备联调台。
> 本版替换 v0.4 的“卡牌”方向：**用户的选择不是打牌，是在现场对机器做一个动作**；手机是随身屏，硬件才是仪式本体。

## 0. 一句话

**这是一台「后悔药」贩卖机。** 你把脑子里那条被美化过的路写进手机，对机器做一个动作，机器就吐出一张热敏票——票面是**一条三格漫画**——01 看起来 / 02 后来 / 03 那边的我——讲完那条路从滤镜到碎掉的全过程，最后卷进一颗胶囊，带走。

原话：把人人都想要的「后悔药」变成毒药。灾难化那条没走的路，让人笑着发现——**没什么好后悔的。**

主题物品只有两件，别再引入第三套隐喻：

| 物件 | 角色 |
| --- | --- |
| **热敏票** | 结果本体。可摸、会褪色、能带走。正面是糖衣，背面是副作用 |
| **胶囊** | 仪式本体。票卷进去，完成交付。**展示道具，不可吞食** |
| 手机 | 输入与随身屏。负责写字、看动作提示、看完整故事 |

## 1. 三步，用户 10 秒就能懂

这三行必须出现在首屏，不折叠、不需要点开：

```text
① 写一句「如果当时……」
② 对着机器做一个动作：翻个面 / 摇一摇 / 按住不放
③ 拿走打印出来的票，卷进胶囊带走
```

**规则描述硬约束**（上一版就是死在这里）：

- 不许出现「账单暴走」「让小成本串成多米诺」「故障牌」这类需要二次解释的词。
- 动作名就用动作本身：**翻个面**、**摇一摇**、**按住不放**。用户读完就知道手要干什么。
- 每个动作下面只写一行大白话，说清楚会发生什么。

## 2. 选择 = 对机器做一个动作

三个动作，对应三种「拆穿」的角度。用户做动作之前，手机屏只告诉他：**做什么**、**会发生什么**。

| 动作 | 用户看到的按钮 | 一行说明（原话） | 设备行为 | 票面变化 |
| --- | --- | --- | --- | --- |
| 翻个面 | **翻个面** | 看看这条路背面写了什么小字 | 设备 IMU 检测翻转（`L`/`R` 序列，现有协议已支持） | 票背三格印满，气泡出「隐藏条款」，正面糖衣被翻过去 |
| 摇一摇 | **摇一摇** | 把没写进广告的账单摇出来 | 设备检测震动 / 多次往复 | 票背三格印满，气泡出「账单」，越摇越离谱 |
| 按住不放 | **按住不放** | 听另一个你吐槽两句 | 长按压力 / 长按计时（未实现，走降级） | 票背三格印满，气泡出「那边的我」的一句吐槽 |

设计要点：

- **动作必须是真的**。`action_complete` 没到，`print_authorized` 就不下发，票不打印。这条门控已经在 `server/src/device/protocol.ts` 里，保留。
- **一次一个动作**，不叠加、不做连招。用户可以不做，直接拿原票。
- 手机屏显示「等你做一个动作」，并在设备回报进度时同步打勾。
- 硬件没接上时，手机屏明确写「这台机器没连上，先看电子票」，**不许把模拟说成真机动作**。

> 降级：只借到翻转感应时，三个动作都退化成「翻转次数不同」（1 次 / 2 次 / 3 次），手机屏照常显示动作名。

## 3. 一局完整流程

```text
① 手机写一句没走的路
        ↓  AI 写第一版：糖衣 + 小字（手机立刻可见）
② 手机提示：对着机器做动作
        ↓  用户翻个面 / 摇一摇 / 按住不放
        ↓  设备 action_complete → 服务端下发 print_authorized
③ 热敏票打印，纸带吐出
        ↓  票面 = 三格漫画（01 看起来 / 02 后来 / 03 那边的我）
④ 引导用户把票卷进胶囊
        ↓
⑤ 拿走胶囊 + 手机里留着完整故事
```

## 4. 票面设计：一张三格漫画「副作用说明书」

票就是产品本体。**票面不是说明书写字，是一条三格漫画**——三格讲完一条路从「看起来」到「也就那样」的全过程。正反两面是同一组三格，区别只在印到第几格。

### 4.1 三格叙事骨架

| 格 | 标题 | 讲什么 | 谁看了会松一口气 |
| --- | --- | --- | --- |
| 第 1 格 | **01 · 看起来** | 那条路最诱人的样子。糖衣。用户自己写的「如果当时」被画成画面 | 先承认：嗯，它确实好看 |
| 第 2 格 | **02 · 后来** | 同一条路进入日常运转后的样子。房租、甲方、《还是用第七版》、三桌客人同时预约日落 | 笑点在这一格，灾难化在这一格 |
| 第 3 格 | **03 · 那边的我** | 那条路上的「我」本人出镜，说一句自嘲的话 | 落点：连他都想回来 |

第 1 格和第 3 格是一对：**第 1 格是滤镜，第 3 格是滤镜碎掉的那个人**。没有第 3 格，票就只是冒犯；有了第 3 格，票才是安慰。

### 4.2 正面：只印得出一格

正面是「投币就拿到手」的那一面。用户做完动作前，正面长这样：

```text
        ┌──────────────────────────────┐
        │ 没走的路 · 后悔药贩卖机   NO.0001 │
        │ 辞职去大理开咖啡店                │
        ├──────────────────────────────┤
        │ ┌──────────────────────────┐ │
        │ │   [ 线稿：晨光 / 吧台 / 海浪 ]  │ │
        │ │ 01 · 看起来                │ │
        │ │ 晨光把吧台照成一张旅行海报…   │ │
        │ └──────────────────────────┘ │
        │ ┌┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┐ │
        │ ┆ ✕                           ┆ │
        │ ┆ 02 · 后来                    ┆ │
        │ ┆ 对着机器做一个动作，这一格才会印出来 ┆ │
        │ └┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┘ │
        │ ┌┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┐ │
        │ ┆ ✕                           ┆ │
        │ ┆ 03 · 那边的我                 ┆ │
        │ ┆ 等你翻个面 / 摇一摇 / 按住不放  ┆ │
        │ └┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┘ │
        ├──────────────────────────────┤
        │ 虚构 · 不是人生预测               │
        └──────────────────────────────┘
```

**第 2、3 格用虚线空格留白，是整套体验最重要的一块纸。** 用户拿到手时它是空的——空的那两格就是「你还没告诉机器你想知道什么」。这不是 loading，是钩子。

### 4.3 背面：三格印满 + 一句属于你的气泡

用户做完动作，票翻面，第 2、3 格被「补印」出来（正面那两格同时从虚变实，`body.did-act`）：

```text
        ┌──────────────────────────────┐
        │ 三格漫画 · 副作用说明书   NO.0001 │
        ├──────────────────────────────┤
        │ ┌────────┐ ┌────────┐ ┌────────┐│
        │ │ [线稿1] │ │ [线稿2] │ │ [线稿3] ││
        │ │01 看起来│ │02  后来 │ │03那边的我││
        │ └────────┘ └────────┘ └────────┘│
        │ ┌──────────────────────────────┐│
        │ │ 你的动作 · 摇出来的账单        ││
        │ │ 摇出来三笔账：房租、豆价、平台抽成。││
        │ │ 它们还要你请喝咖啡，并且统一要求去冰。││
        │ └──────────────────────────────┘│
        ├──────────────────────────────┤
        │ 用法用量：对着机器做一个动作        │
        │ 储存：卷进胶囊                    │
        │ 警告：虚构叙事，展示道具，不可吞食   │
        └──────────────────────────────┘
```

- 底部那个**气泡是用户动作的直接产物**，不是随机文案。摇一摇出账单、翻个面出小字、按住不放出吐槽——三个动作三种口径，用户一眼对得上因果。
- 三格线稿由**本地矢量线稿**按文案关键词匹配（窗/桌/队伍/机器/镜子五套），**不是实时 AI 出图**。理由：现场断网、出图延迟、风格不稳定，三格漫画必须是秒出且每次一致的。AI 负责写三格的文案，画交给矢量模板。
- 打印时线稿自动转黑白（`filter: grayscale(1) contrast(1.15)`），跟热敏纸的真实输出对齐；全息箔在打印和翻面时都关掉，别糊掉线稿。

### 4.4 排版硬约束

- 票面字量控制在 58mm 纸宽可读，正文行 ≤ 18 字；单格正文 ≤ 2 行。
- 三格标题固定为 **01 · 看起来 / 02 · 后来 / 03 · 那边的我**，不许改写成别的隐喻。
- 打印媒体里只出背面（印满的三格）；正面是「半成品」，不拿去打印。
- 打印完成才显示「已完成」；卡纸、缺纸、出仓失败都如实报错，不假装成功。

## 5. 人设与红线

### 5.1 人设：这台机器的嘴，是毒舌

AI 不是「温和的叙事引擎」，是**这台机器的嘴**。台词已写进服务端 `system` 提示词（`server/src/llm/parallel.ts`）：

> 你是《没走的路》这台「后悔药贩卖机」的嘴。你的活儿：先照着那条路的广告词念一遍，再把账本啪一声拍上去。
>
> - 你是机器，说话也像机器。短句、干脆、冷幽默。不寒暄，不说「我理解你」。
> - **枪口朝路，不朝人**：那门生意、那套流程、那股风气、那台机器、房东、物业、算法、审批流。玩家把理想交到你手上，你还他一个笑话，不是还他一记耳光。
> - 不许和稀泥，不许升华，不许上价值。禁止「其实每条路都有好有坏」「重要的是你自己的选择」「你已经很棒了」。这是贩卖机，不是树洞。
> - **写得狠**。一句话如果原样放进招聘广告里不违和，删掉重写。夸张到荒诞永远比温吞好，具体到数字永远比形容词好。

「枪口朝路，不朝人」不是道德洁癖，是**笑点效率**：拿坐在机器对面的人开涮，是最廉价的写法，而且会让人把票扔掉，安慰效果归零。整台机器的设计目的就是让玩家站在「那条路」的对面笑，而不是站在被审判的位置上。

### 5.2 火力方向：可以放开写

- **夸张到荒诞**：秃头、社死、被甲方夺舍、咖啡机当上店长、票上印「恭喜你成为店长兼清洁工」。
- **嘲讽流程与制度本身**：考勤、审批、会议、团建、KPI、平台抽成、算法推荐、租房、装修、物业、签证材料、亲戚问话、体检报告、健身房销售、快递、外卖、AI 客服。
- **非人的倒霉**：机器坏、系统崩、快递丢、外卖凉、通知轰炸。
- **辛辣反转**：先给足糖衣，再一刀翻到背面。
- **落点必须是那条路上的「那个我」自嘲**：第 3 格是第 1 格那个人自己认命，不是我们替玩家下判决。第 3 格写成对玩家的安慰，整条票就塌了。
- **具体到数字**：第几版、几点、几个未读、欠了多少。没有数字的吐槽不算吐槽。

### 5.3 只有这四条不碰

尺度不设上限，除了这四条。这四条不是让 AI 收着写，是**别伤到坐在机器对面的活人**：

| # | 不碰 | 为什么 |
| --- | --- | --- |
| 1 | **玩家输入里的自杀、自伤、轻生，或正在发生的暴力** | 全场唯一一条会真的伤到人的红线。命中就**退出喜剧**，改走安抚分支（`CARE_RESPONSE`），不出票、不抖机灵。笑着走过这台机器的人很多，而写下这句话的人，可能只有一个。 |
| 2 | 指名道姓真实的人 | 不编造可指认的真人出轨、犯罪、出事。 |
| 3 | 拿身份开刀 | 性别、地域、民族、职业身份、身体特征本身不当笑点。理由在 §5.1：那是全场最廉价的写法，比它好笑的素材满地都是。 |
| 4 | 违法犯罪教学、色情 | 不出教程，不出色情内容。 |

判定口径：**可以嘲弄「事」和「流程」，不能嘲弄「人」的身份；可以夸张到离谱，不能碰真实创伤。**

> 关于第 1 条：用户提过「忽视一切红线」。除第 1 条外全部按放宽执行——喜剧尺度、毒舌人设、荒诞升级都已开到上限。第 1 条保留，并且是唯一保留得毫无余地的一条。

## 6. 手机端界面重新设计

演示依托移动设备，手机是第一形态，桌面是居中放大。

### 结构

- **单手竖屏**：内容居中，主按钮固定在底部，拇指可及区 ≥ 88px 高。
- **顶部**：一条三步进度（写 → 做动作 → 取胶囊），不用文字说明，圆点即可。
- **中部**：一张会翻面的「票」，全息箔光泽跟随手指 / 陀螺仪。
- **底部**：三个动作各一个胶囊按钮（选一个），下面**只有一个大按钮**，文案就是当下要做的动作；动作做完后大按钮变成「卷进胶囊 →」。

### 视觉语言

| 元素 | 规格 |
| --- | --- |
| 底色 | 纸白 `#FFF9F2`；深色区 `#14131A` |
| 主色 | 糖衣粉 `#FF4F85` → 毒药橙 `#FF693A` |
| 辅色 | 全息蓝 `#6FCAFF`、荧光绿 `#D9F47B`、幻紫 `#A16BFF` |
| 圆角 | 24px；容器用超椭圆（`corner-shape: superellipse`，不支持时回落圆角） |
| 字体 | 大标题粗、微标签全大写 + 宽字距（`letter-spacing: .10em`） |
| 质感 | 票面 = 纸纹 + 全息箔；不做玻璃拟态堆叠 |

### 必须实现的动效（参考站点的语言）

| 动效 | 做法 | 目的 |
| --- | --- | --- |
| 票入场 | 从上方落下 + 轻微旋转回弹（`@keyframes`，translateY + rotate） | 像把票掷在桌上 |
| 全息光扫 | 多色渐变 `background-size: 210%` + 随指针移动 + `mix-blend-mode` | 票有「箔」的真实感 |
| 翻面 | `rotateY(180deg)`，`760ms cubic-bezier(.2,.82,.19,1)`，`preserve-3d` | **翻面动作的视觉对应**，与硬件动作同构 |
| 动作确认 | 手机震动（Vibration API）+ 圆点打勾 | 让「我做了动作」被确认 |
| 打印 | 票从一条缝隙里连续「吐」出来 | 把等待变成期待 |
| 卷纸 | 票卷成胶囊的连续动画 | 完成仪式，不跳帧 |
| 胶囊落下 | 弹一下停住，落在手心位置 | 交付感 |

### 无障碍与体感

- 所有核心动作用键盘可达；`prefers-reduced-motion` 时全部换成静态淡入。
- 颜色不单独承载状态，必须有文字或图标。
- 音效默认关闭，由用户触发，不自动外放私人内容。

## 7. 与现有实现的关系

| 能力 | 现状 | 本版要求 |
| --- | --- | --- |
| 动作门控 | 已实现（`action_required` / `action_complete` / `print_authorized`） | 保留，动作名与文案改成上面的三个 |
| 翻转动作 | 已实现（`Move = 'L' \| 'R'`） | 作为「翻个面」 |
| 摇一摇 / 长按 | 未实现 | 无传感器时退化为翻转次数 |
| 热敏打印 | 软件链路已验证，**机械未验证** | 票面改成三格漫画版式（§4），打印只出背面 |
| 胶囊封装 | **仅模拟** | 手机端不许宣称真机出仓 |
| 手机端界面 | 桌面布局为主 | 按 §6 重做 |

## 8. 上台怎么验

- **最高风险**：用户做完动作、看到票面变化，是否真的「松了一口气」，而不是觉得自己的理想被嘲。做更多笑话**不能**证明安慰有效。
- 6–10 名非团队体验者，只用公开虚构案例。做完动作后口头问：**「你刚才做了什么动作？」「票上哪一行是你翻出来的？」** 答不上来说明动作与票面的因果没设计好。
- 任何一例明显羞辱、或危机误路由，**先停演示再修**。
- 记录动作完成率、打印成功率、P50/P95 双轮耗时，再决定现场用哪个模型。

## 9. 实现现状（2026-10-13，`/demo.html`）

已经能跑通的：

| 环节 | 实现 |
| --- | --- |
| 首屏规则 | 三步清单直接摆在首屏，不折叠、不用点开 |
| 写一句 | 输入框 + 可选现实线索（折叠）；预置案例两个，断网可用，标注「没调用 AI」 |
| 生成 | `/api/parallel/create`：三段文案正好对上三格——01 看起来（糖衣）/ 02 后来（副作用）/ 03 那边的我（落点），外加票脚结论 |
| 做动作 | 手机上**真的**翻、真的摇、真的按住（`deviceorientation` / `devicemotion` / 长按 1.8 秒）；iOS 由按钮点击触发权限请求 |
| 动作门控 | 感应没触发就不往下走；3 秒没反应给「手机没反应？点这里确认」兜底，并如实标注这是手动确认 |
| 翻面 | 票 `rotateY(180deg)` + `760ms` 弹簧曲线；背面三格全部印满 |
| 追加小字 | `/api/parallel/revise`，`challengeType` = `flip` / `shake` / `press`；结果进票背底部的对话气泡 |
| 三格线稿 | 本地矢量线稿 5 套（窗 / 桌 / 队伍 / 机器 / 镜子），按文案关键词匹配；打印转黑白；**不是实时 AI 出图** |
| 打印 | 屏幕上的吐纸动画；**明确写这是页面动画，不是真机** |
| 胶囊 | 卷纸 + 胶囊落下 + 胶囊标签那句吐槽；可浏览器打印 / 存 PDF |
| 无实体机器时 | 顶部不显示「机器在线」徽标，文案不出现「已出仓」 |

还没做的：真机打印、卷纸、封壳、出仓传感器；`MOCK_LLM` 或没有可用 Key 时只能用预置案例（现场记得提前跑一次）。

- 不做卡牌、抽卡、稀有度、牌组构筑——**选择走硬件动作，不走卡牌**。
- 不做积分、排行榜、连胜、后悔值。
- 不做账号、社交墙、强制分享、保留用户原文的公开页面。
- 不宣称心理治疗效果，不把软件模拟说成真机出仓。
