# 没走的路 / Road Not Taken

一个结合生成式模型与实体硬件的黑客松项目。

人们常把没有选择的人生想象得更美好。用户说出一句“如果当时……”，模型不会继续美化那条路，而是生成一段具体、克制、带有代价的平行人生。实体设备通过翻转、摇动和热敏打印，将结果逐格揭示成一张可以带走的“未选择人生小票”。

## 核心体验

1. 用户输入或说出一个未实现的选择。
2. 模型生成一条“去滤镜”的平行人生，包括诱惑、现实代价和意外结局。
3. 设备亮灯并发出提示音，要求用户完成一组翻转动作。
4. 每完成一步，热敏打印机打印一格图文。
5. 用户拿走完整小票，也可扫描二维码在手机上查看和分享。

## 为什么需要硬件

硬件不是手机页面的遥控器，而是作品的叙事媒介：

- 翻转设备对应“翻转一次选择”。
- 等待和逐格打印制造不可跳过的揭晓过程。
- 热敏小票把一次模型生成变成可触摸、会褪色的纪念物。
- 手机负责输入和分享，实体设备负责仪式与最终交付。
