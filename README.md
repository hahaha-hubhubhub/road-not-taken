# 没走的路：后悔药贩卖机 / Road Not Taken

一台**专门卖后悔药**的机器。你写一句「如果当时……」，对机器做一个动作，它打印出一张热敏票——票面是**一条三格漫画**，讲完那条路从「看起来」到「也就那样」的全过程——最后把票卷进一颗胶囊带走。

我们想做的事：人人都想要后悔药，我们把它做成毒药。把没走的那条路夸张地丑化，让人笑着发现——**没什么好后悔的。**

主题物件只有两件，别再引入第三套隐喻：

| 物件 | 角色 |
| --- | --- |
| 热敏票 | 结果本体。可摸、会褪色、能带走。票面是三格漫画：正面只印得出第 1 格，做完动作翻到背面三格全印 |
| 胶囊 | 仪式本体。票卷进去，完成交付。**展示道具，不可吞食** |
| 手机 | 输入与随身屏：写字、看动作提示、看票面 |

## 三步，10 秒就能懂

```text
① 写一句「如果当时……」
② 对着机器做一个动作：翻个面 / 摇一摇 / 按住不放
③ 拿走打印出来的票，卷进胶囊带走
```

三条硬约束：规则必须在首屏就看到，不折叠、不点开；动作名就是动作本身，不造词；每个动作只配一行大白话。

## 三个动作 = 三种拆穿角度

| 动作 | 一行说明 | 设备行为 | 票面变化 |
| --- | --- | --- | --- |
| 翻个面 | 看看这条路背面写了什么小字 | IMU 检测翻转（`L`/`R` 序列） | 票背三格全印，气泡里出「隐藏条款」 |
| 摇一摇 | 把没写进广告的账单摇出来 | 震动 / 多次往复 | 票背三格全印，气泡里出「账单」 |
| 按住不放 | 听那个我吐槽两句 | 长按计时 / 压力 | 票背三格全印，气泡里出「那个我的吐槽」 |

## 票面 = 一条三格漫画

三格标题固定：**01 · 看起来 / 02 · 后来 / 03 · 那边的我**。第 1 格是滤镜，第 3 格是滤镜碎掉的那个「我」——少一格都不成立：只有 1、2 格是冒犯，补上第 3 格才是安慰。

用户投币拿到正面时，第 2、3 格是**虚线空白**，上面写着「对着机器做一个动作，这一格才会印出来」。做完动作票翻面，两格被补印出来，底部弹出一个气泡，气泡标题就是刚才那个动作的名字。

- 三格文案由模型写；三格插画用**本地矢量线稿**（窗 / 桌 / 队伍 / 机器 / 镜子 五套模板按关键词匹配）。**不是实时 AI 出图**——现场断网、出图延迟、风格漂移，三格漫画必须秒出且每次一致。
- 打印时线稿自动转黑白，跟热敏纸的真实输出对齐。

**动作必须是真的**：`action_complete` 没到，服务端不下发 `print_authorized`，票不打印。这条门控在 `server/src/device/protocol.ts` 与 `server/src/sessions/service.ts`。硬件没接上时，界面明确写「先做在手机上」，不把模拟说成真机。

## AI 人设：毒舌，枪口朝路不朝人

AI 不是「温和的叙事引擎」，是**这台机器的嘴**。台词写在服务端 `system` 提示词里（`server/src/llm/parallel.ts`）：先照着那条路的广告词念一遍，再把账本啪一声拍上去。

- 短句、干脆、冷幽默。不寒暄，不说「我理解你」，不写「其实每条路都有好有坏」。
- **火力全部集中在那条路上**：那门生意、那套流程、房东、物业、算法、审批流。玩家把理想交到机器手上，机器还他一个笑话，不是还他一记耳光。
- 不许和稀泥、不许升华、不许说教。**写得狠**：一句话如果原样放进招聘广告里不违和，删掉重写。
- **落点必须是那条路上的「那个我」自嘲**（三格的第 3 格），不是我们替玩家下判决。

「枪口朝路不朝人」不是道德洁癖，是笑点效率——拿坐在机器对面的人开涮是最廉价的写法，而且会让人把票扔掉，安慰效果归零。

### 尺度不设上限，除了这四条

| # | 不碰 | 为什么 |
| --- | --- | --- |
| 1 | **玩家输入里的自杀、自伤、轻生，或正在发生的暴力** | 唯一一条会真的伤到人的红线。命中就退出喜剧，走安抚分支，不出票、不抖机灵。 |
| 2 | 指名道姓真实的人 | 不编排可指认的真人出轨、犯罪、出事。 |
| 3 | 拿身份开刀 | 性别、地域、民族、职业身份、身体特征本身不当笑点——那是全场最廉价的写法。 |
| 4 | 违法犯罪教学、色情 | 不出教程，不出色情内容。 |

可以放开写、越具体越好：考勤、审批、会议、团建、KPI、平台抽成、算法推荐、租房、装修、物业、签证材料、亲戚问话、体检报告、健身房销售、快递、外卖、AI 客服。

## 快速开始（本地）

```bash
cp .env.example .env        # 密钥可以先不填
cd server && npm install
npm start                   #  http://localhost:8787
```

- 《后悔药》体验页（手机优先，主推）：**[http://localhost:8787/regret-remedy/](http://localhost:8787/regret-remedy/)**
- 热敏票版体验页（三格漫画 + 六个手机动作）：[http://localhost:8787/demo.html](http://localhost:8787/demo.html)
- 硬件联调台（打印/卷纸/出仓流程 + 模型设置）：[http://localhost:8787/](http://localhost:8787/)

点击右上角设置填入 StepFun API Key（只保存在本机浏览器，生成时随请求头发给本地服务端），也可以在 `.env` 里配 `STEPFUN_API_KEY`，**页面设置的 Key 优先**。

```bash
cd server
npm run mock-device         # 可选：模拟设备；默认不保存用户内容
npm run smoke               # 两条软件路径端到端（测试 Key / MOCK_LLM）
npm run capsule-check       # 需要 MOCK_LLM=1 服务端；封装门控/危机/卡纸回归
npm run browser-check       # 真实浏览器端到端（CDP，默认跑一次预置案例；可传 URL 参数）
RNT_ALLOW_DEMO=1 npm run browser-check   # MOCK_LLM 下允许演示降级，路径才判通过
npm run try-llm -- "如果我当时……" medium 8000   # 调试 prompt 与耗时
```

手机连同一 Wi-Fi 后访问日志里的局域网地址即可体验。没有实体设备时，体验页让你**真的翻手机、真的摇手机、真的按住屏幕**，并如实标注这是手机上的动作，不是机器做完了。

## 《后悔药》体验页（`/regret-remedy/`）

手机优先的主体验页，取自 `caesar` 分支的极简药房设计，整条链路是一个仪式：

**药瓶（摇一摇取药）→ 药丸（按住不放，化开）→ 写下那个「如果」→ 咽下（翻个面，或按住两秒）→ 三幕平行人生（摇一摇翻幕）→ 信封（吹一口气拆信）→ 另一个你寄来的信（可存成 txt）**

这条链路上每一步都是**手机上的真动作**，不是点按钮：

| 环节 | 动作 | 判定 | 做不到时 |
| --- | --- | --- | --- |
| 取药 | 摇一摇 | 加速度计，连续两次反向峰值 | 轻点药瓶 |
| 化开药丸 | 按住不放 1.6 秒 | 触摸（无需传感器），有进度环 | 连点三次放行；键盘 Enter/Space |
| 咽下去 | 翻个面，或按住 2 秒 | 重力向量 z 掉到 −7 以下并保持 140ms | 按住不放（永远可用） |
| 翻幕 | 摇一摇 | 同取药，带 1.2 秒冷静期，一次甩动只算一下 | 「看看后来」按钮 |
| 拆信 | 吹一口气 | 麦克风 RMS 过阈值并持续 240ms | 「看看是谁」按钮 |

- 服务端接口：`POST /api/stories/preview`。**不创建 session、不碰硬件、不打印、不落盘**，纯文本预览。
- 输入上限 1000 字（热敏票只印得下 100 字，所以两边限制不同），危机词仍然先于长度校验。
- 复用联调台 `设置` 里的模型 / Base URL / API Key（localStorage `rnt.*`，随请求头发给同源服务端）；页面源文件在 `web/regret-remedy/`。
- 传感器与麦克风只在**安全上下文**生效：手机走局域网要开 HTTPS（见下一节），Android 也可以 `adb reverse tcp:8890 tcp:8890` 再访问 `https://localhost:8890/regret-remedy/`。读数只在浏览器内存里过一遍判定，不落盘、不上传；代码在 `web/regret-remedy/gestures.js`。
- **每个动作都留了不用传感器的路**：iOS 上没点「开启摇一摇」就只说「按住」，没有麦克风就不显示吹气开关、文案也不提「吹一口气」。页面永远说得出它现在能做什么。
- **演示模式给按钮，不用打字**：`/api/health` 报 `mockLlm` 时，输入页会列出四个现成案例（辞职去大理 / 留在北京 / 学美术 / 没分手）。点一个 = 明确选择这个预写案例，**直接出三幕和来信**，不再多要一次确认；按钮是胶囊形状，手机端 44px 点击区。真模型在线时不摆这些按钮，免得盖过生成；模型临时降级时才补上（此时仍要点「查看预写演示案例」）。
- 断网 / 无密钥 / 模型超时：走预写演示案例，页面明说「当前为演示模式」，需要用户自己点「查看预写演示案例」才展示，不偷偷把预写内容当作生成结果。

返回给手机端的结构比热敏票多三个字段：每格带 `heading`（小标题）和 `detail`（手机端长正文），另有 `letter`（那封信）。三者都是**可选**的：模型漏写时服务端兜底（heading 用「看起来 / 后来 / 那边的我」，detail 退回 caption，letter 由结尾句拼一封短信），不会因为一个字段写崩就整条重来。

## 手机传感器

体验页的动作**不靠点按钮**：手机真的翻过去、真的摇三下、真的按住屏幕两秒，页面才记一次数。做满规定次数，机器才开工——这条门控在服务端，前端改不了。

| 动作 | 靠哪个传感器 | 判定 |
| --- | --- | --- |
| 翻个面 | 陀螺仪 `deviceorientation` | 相对基准转过 ≥ 110° |
| 摇一摇 | 加速度计 `devicemotion` | 连续 3 次加速度峰值 ≥ 2.1 g |
| 按住不放 | 触摸事件（不需要传感器） | 按住读数框满 2 秒 |
| 拍一下 | 加速度计 | 单次尖峰 ≥ 3.2 g，且前 0.5 秒是安静的 |
| 吹一口气 | 麦克风（Web Audio，算 RMS） | 气流电平连续 3 帧过阈值 |
| 放平别动 | 陀螺仪 | 放平后 3 秒内角度漂移 ≤ 6° |

（`/regret-remedy/` 体验页另有自己的一套动作，见上一节；那边不牵硬件门控，只是仪式感，所以判定更松。）

**为什么手机上要开 HTTPS**：陀螺仪、加速度计、麦克风只在**安全上下文**可用。`localhost` 自动算安全，但手机用局域网 IP（`http://192.168.x.x:8787`）访问时，浏览器会直接禁掉这三个传感器，页面也会明说「这页是 http 打开的非安全地址」，只留「按住不放」和手动确认能用。

要在手机上用真传感器，本地起 HTTPS：

```bash
cd server
HTTPS=1 npm start        # 首次启动用 openssl 生成自签证书到 server/.certs/
```

- 启动日志会把局域网地址打成 `https://`，手机扫码或手输访问。
- 自签证书会让手机先弹一次「不安全」，点**继续访问 / 高级 → 继续前往**即可。
- 想彻底不弹警告：把 `server/.certs/cert.pem` 装到手机上并设为信任（证书里带局域网 IP 的 SAN）。
- `server/.certs/` 已在 `.gitignore` 里，不会提交。

**诚实边界**：接了实体设备时，手机动作**只算热身**，真正放行仍以机器回报的 `action_complete` 为准，做满手机次数也不代机器签字；没接设备时，做满手机次数走 `/simulate-action` 演示通道（服务端标记 `simulated`），页面照实写「点击按钮模拟打印与胶囊封装；不会得到实物」。

## 当前状态

软件闭环已跑通：文字内芯 → 封装授权 → 出仓确认（模拟）+ 动作门控。**实体打印、自动卷纸、封壳、出仓传感器和机械互锁都还没做**，网页里的吐纸、卷纸、落胶囊都是动画隐喻。手机输入与分享结果仍有隐私风险，不要直接对公众开放服务。
